# Proposal and invoice

Produce a Markdown draft with: client and business details, scope (pages, SEO tasks, revisions included), deliverables, timeline, price from the user's rate card, payment terms, what the client must supply (photos, logo, access), and ownership of the finished work.

Use `{placeholders}` for any price or term the user has not set; never invent rates. Save the draft with `file_write`. Sending the document or any payment link is an outward action that needs the user's approval.
